# Experiment 01

## Title

Create Regular Expressions in Python for Detecting Word Patterns and Tokenizing Text

## Aim

To develop Python programs using Regular Expressions (Regex) for detecting word patterns, extracting specific text patterns, and tokenizing text into meaningful units such as words, numbers, and punctuation.

## Software Requirements

- Python 3.x
- VS Code
- re Module

## Algorithm

1. Import the `re` module.
2. Store the sample text.
3. Create regex patterns.
4. Extract words.
5. Extract numbers.
6. Detect email IDs.
7. Detect phone numbers.
8. Detect dates.
9. Detect URLs.
10. Detect capitalized words.
11. Tokenize the text.
12. Display the results.

## Files

- experiment1.py
- requirements.txt
- sample_input.txt
- sample_output.txt

## Result

The Python program successfully detected word patterns, extracted emails, phone numbers, dates, URLs, capitalized words, and tokenized the text using Regular Expressions.
